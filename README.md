# Portafolio · Alisson Quijano

Sitio personal estático (HTML y CSS, sin dependencias) con mis proyectos, experiencia y contacto.

## Estructura

```
index.html        proyectos, habilidades y reconocimientos
experiencia.html  experiencia y formación
css/styles.css  estilos (paleta, tipografía, diseño responsive)
js/main.js      pestañas de proyectos
img/foto.jpg    foto de perfil
```

## Publicarlo con GitHub Pages

1. Sube `index.html`, `experiencia.html` y las carpetas `css/`, `js/` e `img/` a la raíz del repositorio.
2. En el repositorio, ve a **Settings → Pages**.
3. En **Source**, elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`. Guarda.
4. En uno o dos minutos el sitio queda en `https://<tu-usuario>.github.io/<nombre-del-repo>/`.

Si el repositorio se llama `sonali-218.github.io`, la dirección será `https://sonali-218.github.io/`.
